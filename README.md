# Система обработки заявок

API для создания и обработки заявок технической службе колледжа.

## Установка и запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r "БИБЛИОТЕКИ НУЖНЫЕ!.txt"
$env:SECRET_KEY = "замените-на-длинный-случайный-секрет"
uvicorn main:app --reload
```

Документация API после запуска доступна по адресу `http://127.0.0.1:8000/docs`.

Чтобы разрешить регистрацию пользователей с ролью техника, задайте переменную
окружения `TECHNICIAN_SECRET_CODE` перед запуском. Без нее регистрация доступна
только с ролью преподавателя. Не используйте секреты по умолчанию и не
публикуйте их в репозитории.

Файлы загруженных изображений и локальная база данных SQLite создаются рядом с
приложением и исключены из Git.
